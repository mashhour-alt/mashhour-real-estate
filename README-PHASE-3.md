## بعد الرفع — أول مرة

### 1) افتح لوحة الإدارة
```
mashhour-real-estate.mashhour.workers.dev/admin
```
(الرابط مش ظاهر في القائمة عمدًا — للأدمن بس)

### 2) اعمل كلمة سر (مرة واحدة)
أول مرة هيطلب منك تعمل كلمة سر (8 حروف على الأقل). دي بتتخزن مشفّرة في قاعدة البيانات. أي دخول بعد كده هيطلب نفس الكلمة.

### 3) ضيف أول مقال
- **القسم:** منطقة / مطور / مشروع
- **مرتبط بـ:** اكتب اسم المنطقة أو المطور (فيه اقتراحات من بياناتك). سيبها فاضية = المقال يظهر في كل صفحات القسم
- **العنوان (EN)** و **اسم الكاتب** إجباريين
- الباقي اختياري: عنوان عربي، صورة غلاف (رابط)، صورة الكاتب (رابط)، رقم الكاتب، ملخص، ونص المقال — كله بالعربي والإنجليزي

### 4) شوف النتيجة
افتح صفحة المناطق أو المطورين أو المشاريع — المقال هيظهر تحت، وعليه: العنوان + صورة الغلاف + صورة الكاتب + اسمه + رقمه (زي ما طلبت بالظبط). دوس على المقال يفتح كامل.

## إيه اللي اتعمل

### قاعدة البيانات (D1)
- جدول `articles` فيه كل حقول المقال (عربي/إنجليزي، بيانات الكاتب، القسم، الحالة)
- جدول `settings` لكلمة سر الأدمن (مشفّرة SHA-256 + salt)

### الحماية
- كلمة سر واحدة للوحة الإدارة، بتتعمل أول مرة وبتتخزن مشفّرة
- أي تعديل أو حذف أو إضافة محتاج الكلمة — الزوار يقدروا يشوفوا المقالات بس

### لوحة الإدارة `/admin`
- إضافة/تعديل/حذف مقالات
- نشر أو حفظ كمسودة (المسودة متظهرش للزوار)
- كل الحقول بالعربي والإنجليزي

### عرض المقالات
- بتظهر تلقائيًا في صفحات المشاريع والمطورين والمناطق
- أعلى كل مقال: العنوان + الغلاف + صورة الكاتب + اسمه + رقمه (زر اتصال)
- تفتح كامل في نافذة، وبتتبع لغة الموقع (عربي/إنجليزي)

## ملاحظات

- **الصور حاليًا بروابط (URL).** رفع الصور مباشرة من الجهاز محتاج تخزين R2، وده لسه `null` في الإعدادات — ممكن نفعّله في مرحلة جاية لو حبيت
- **ده أساس لوحة الإدارة.** بعد ما نتأكد إنها شغالة، نقدر نضيف عليها إدارة المشاريع نفسها (صور، فيديوهات، أسعار) بنفس الطريقة
- لو القاعدة اشتغلت تمام، المرحلة الجاية المنطقية: **صفحات المناطق المستقلة** (كل منطقة صفحتها) وربطها بالمقالات والمشاريع
