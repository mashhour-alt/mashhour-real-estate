## اللي اتعمل

### مسارات المترو (ظاهرة دايمًا)
- **الخط الأحمر** (أحمر) — المحطات كلها
- **الخط الأخضر** (أخضر) — المحطات كلها
- **الخط الأزرق تحت الإنشاء** (أزرق متقطّع وشفاف) — المسار المعلن
- نقطة عند كل محطة، واسم المحطة يظهر لما تعدّي عليها

### المعالم العملاقة (طبقة تقدر تطفّيها)
- برج خليفة، برج العرب، نخلة جميرا، دبي مول، متحف المستقبل، عين دبي، دبي فريم، إكسبو سيتي...
- **التحت-إنشاء بشفافية** (زي ما طلبت): كريك تاور، مطار آل مكتوم، نخلة جبل علي، جزر دبي، نخلة جبل علي
- زرار "◆ Landmarks" في ركن الخريطة يشغّلها/يطفّيها

### مفتاح الخريطة (Legend)
- ركن الخريطة فيه مفتاح بألوان الخطوط + زرار المعالم

## ملاحظات مهمة (بصراحة)

1. **إحداثيات المترو والمعالم استرشادية** — دقيقة بما يكفي للعرض العام، مش دقة هندسية للمتر.

2. **"رسم المعالم بأشكالها الحقيقية" (زي شكل برج خليفة) لم يُنفّذ** — ده شغل تصميم ضخم (كل مبنى SVG بإيد، أسابيع عمل). بدله: أيقونة ◆ مميزة باسم المعلم، والتحت-إنشاء بشفافية. بتوصّل نفس الفكرة عمليًا.

3. **المشاريع لسه على مستوى المنطقة** (مش كل مبنى بإحداثياته) — لأن الإحداثيات الدقيقة لـ2,308 مشروع مش موجودة في بياناتك. ده محتاج مصدر (يدوي أو Google API).

4. **لوجو المطور على المشاريع** لسه — مربوط باللوجوهات اللي متجمعتش.
