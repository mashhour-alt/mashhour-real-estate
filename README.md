# النظام الهجين للخريطة — دقيق + تقريبي

## الفكرة
- المشاريع اللي ليها إحداثيات مؤكدة → **نقطة زرقاء دقيقة** على مكانها بالظبط
- الباقي → يفضل على **مستوى المنطقة** (زي دلوقتي)
- العداد بيوضّح: كام مشروع "exact" (دقيق)

كل ما تضيف إحداثيات مشروع، يتحوّل تلقائيًا من تقريبي لدقيق.

## الملفات (3)
- app/ProjectMap.tsx (معدّل)
- app/globals.css (معدّل)
- public/data/coordinates.json (جديد — فاضي، تملاه تدريجيًا)

## الرفع
Upload files → اسحب app و public
Commit directly to the main branch

## إزاي تضيف إحداثيات مشروع

افتح ملف public/data/coordinates.json على GitHub وعدّله.
داخل "projects": {} حط كل مشروع كده:

  "projects": {
    "Burj Binghatti": { "lat": 25.1858, "lng": 55.2620 },
    "Six Senses Residences": { "lat": 25.1015, "lng": 55.1620 }
  }

مهم: اسم المشروع لازم يطابق الاسم في offplan.json بالظبط.

أول ما تحفظ وترفع، المشروع هيظهر كنقطة زرقاء دقيقة على الخريطة.

## دلوقتي الملف فاضي
يعني كل المشاريع لسه على مستوى المنطقة. أول ما تبدأ تملا، تبدأ النقط الدقيقة تظهر.
