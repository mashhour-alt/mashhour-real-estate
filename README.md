## اللي اتضاف لصفحة المشاريع

فلاتر جديدة فوق القايمة:
- **نطاق السعر:** أقل من مليون / 1-2 مليون / 2-5 مليون / أكثر من 5 مليون
- **سنة التسليم:** 2026 لحد 2032 (من بياناتك)
- **الترتيب:** السعر (من الأقل / من الأعلى) / التسليم (الأقرب)

كل الفلاتر بتشتغل مع بعض ومع البحث والمنطقة والمطور الموجودين.
