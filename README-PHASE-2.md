## طريقة الرفع على GitHub

### أ) الملف الجديد `app/roi/page.tsx`

1. الريبو → **Add file** → **Upload files**
2. اسحب مجلد `app` من الحزمة دي (اللي جواه `roi/page.tsx` بس)
3. تحت: اكتب رسالة الـ commit في **خانة الـ commit** (مش جوه الملف)
4. اختار **Commit directly to the main branch** → Commit changes

### ب) الملفين المعدّلين

لكل ملف:
1. ادخل على الملف في الريبو
2. أيقونة القلم ✏️
3. Cmd+A → احذف → الصق المحتوى الجديد
4. زرار **Commit changes...** الأخضر فوق
5. **Commit directly to the main branch** → Commit

> ممكن ترفع التلاتة مرة واحدة عن طريق Upload files ودي أسرع — اسحب `app` و `lib` مع بعض.

## إيه اللي اتعمل

### الصفحة الجديدة `/roi`
- ظهرت في القائمة الرئيسية وفي كروت الصفحة الرئيسية تلقائيًا
- شغالة بالعربي والإنجليزي والإيطالي، ومع RTL

### المدخلات (زي الشيت بالظبط)
- المساحة (قدم²)
- سعر القدم (درهم)
- إيجار القدم السنوي (درهم)
- نسبة الزيادة المتوقعة (%)
- مصاريف سنوية (اختياري)

### خطة الدفع
- جدول قابل للتعديل بالكامل: تضيف مراحل، تحذف، تغيّر الأسماء والنسب
- كل مرحلة ليها اختيار **"ضمن رأس المال"** — ده اللي بيحدد حساب الـ ROE (زي عمود نعم/لا في الشيت)
- المبلغ بيتحسب تلقائيًا لكل مرحلة
- تنبيه أحمر لو المجموع مش 100%

### النتائج
- سعر العقار / الإيجار السنوي / صافي الإيجار / السعر المتوقع بعد سنة / الزيادة الرأسمالية
- **ROI** و **ROE** في بوكسين كبار واضحين
- رأس المال المدفوع / العائد الكلي سنة 1 / فترة استرداد رأس المال

### إضافة مفيدة
**"املأ من مؤشر منطقة"** — قائمة بمناطق دبي من بياناتك، تختار منطقة فيملأ سعر القدم وإيجار القدم من مؤشرات المنطقة (سعر القدم × العائد الإجمالي). ده بيدي نقطة بداية مبنية على بياناتك بدل أرقام من الهوا.
